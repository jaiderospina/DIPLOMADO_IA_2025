**UTILIDADES**

- **Teachable Machine** es una herramienta web de Google que facilita la creación de modelos de **aprendizaje automático** sin necesidad de escribir código. Su principal utilidad es democratizar el acceso a la IA, permitiendo que cualquier persona (educadores, estudiantes, artistas, etc.) entrene a un ordenador para reconocer imágenes, sonidos o poses de manera rápida y sencilla. Los modelos creados se pueden exportar para usarlos en proyectos, sitios web o aplicaciones, lo que lo convierte en una herramienta ideal para la experimentación y la educación en IA.- **Teachable Machine**: una herramienta de Google para crear y entrenar modelos de machine learning

Teachable Machine es una plataforma web desarrollada por Google que permite a cualquier persona, sin necesidad de conocimientos en programación, **crear y entrenar modelos de aprendizaje automático** de forma rápida y sencilla. Los usuarios pueden entrenar modelos de reconocimiento de imágenes, sonidos y poses subiendo datos desde su ordenador o capturándolos directamente con la cámara web o el micrófono. Una vez entrenados, estos modelos pueden exportarse y utilizarse en proyectos, sitios web o aplicaciones, lo que convierte a Teachable Machine en una herramienta excelente para la educación, la experimentación y la democratización de la IA.
