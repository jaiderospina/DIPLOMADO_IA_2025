**UTILIDADES**

- **Teachable Machine** es una herramienta web de Google que facilita la creación de modelos de **aprendizaje automático** sin necesidad de escribir código. Su principal utilidad es democratizar el acceso a la IA, permitiendo que cualquier persona (educadores, estudiantes, artistas, etc.) entrene a un ordenador para reconocer imágenes, sonidos o poses de manera rápida y sencilla. Los modelos creados se pueden exportar para usarlos en proyectos, sitios web o aplicaciones, lo que lo convierte en una herramienta ideal para la experimentación y la educación en IA.- **Teachable Machine**: una herramienta de Google para crear y entrenar modelos de machine learning
